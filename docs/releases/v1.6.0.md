# MorniCraft 1.6.0

- Neu: Ränge direkt im Spiel vergeben – `/vip Steve`, `/mod Steve`, `/media Steve` … (jeder Rang, auch der Anfang des Namens). `/vip Steve weg` nimmt ihn wieder. Auch `/rang Steve vip` und aus der Konsole.
- Dürfen: OPs und Ränge mit `mornicraft.ranks` (Owner und Admin). Niemand vergibt Ränge über dem eigenen.
- Ohne MorniHosting bleiben die Ränge in `plugins/MorniCraft/ranks-ingame.yml`; mit MorniHosting landen sie im Dashboard.
- `/team` zeigt auch im Spiel vergebene Ränge.
- Geändert: Das Team-Fenster heißt jetzt `/ansehen <spieler>` (auch `/inspect`), weil `/mod` jetzt den Moderator-Rang vergibt. Ducken + Rechtsklick geht wie bisher.

Update: neue `MorniCraft.jar` in den `plugins`-Ordner, Server neu starten. Mit MorniHosting kommt sie von selbst.
