## MorniCraft 1.3.0 – Rang-Abzeichen

- **Neu: Rang-Abzeichen im Chat.** Statt „♛ Owner · Morni“ steht ein kleines farbiges Schild mit Pixel-Icon und Rang-Name vor dem Spieler, wie auf großen Servern.
  - Spieler bekommen dafür beim Betreten ein winziges Texturpaket angeboten (nur ein paar Bilder, nie Pflicht).
  - Wer ablehnt, und alle Bedrock-Spieler, sehen weiter die Symbole. Jeder sieht also immer etwas Passendes.
  - Tab-Liste und Name über dem Kopf zeigen weiter das Symbol.
- **Mit MorniHosting:** Das Panel zeichnet die Abzeichen aus deinen Rängen (Name, Symbol, Farbe) und stellt das Paket bereit. Einschalten unter Ränge → „Abzeichen im Chat“; das Panel braucht dafür eine Domain.
- **Ohne MorniHosting:** eigenes Paket in der `config.yml` eintragen (`pack: { url, sha1 }`, pro Rang `badge`).

**Update:** `MorniCraft.jar` im Ordner `plugins/` austauschen und den Server neu starten.
